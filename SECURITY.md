# Security Policy

## Supported versions

Only the latest release receives security fixes. Murmator updates itself through Sparkle, so the fix reaches
users as a regular update.

## Reporting a vulnerability

Please do not open a public issue. Report the problem privately through
[GitHub private vulnerability reporting](https://github.com/bshk-app/murmator/security/advisories/new).

Include the affected version, the steps to reproduce, and the impact you expect. You will get a first reply
within 7 days. After a fix ships, the advisory is published and you are credited unless you ask otherwise.

## Scope

In scope: the Murmator app, its update channel (Sparkle appcast and signed releases), and the model downloads it
performs on first launch.

Out of scope: vulnerabilities in third-party dependencies that are already reported upstream, and issues that need
an attacker who already controls the user's Mac.
